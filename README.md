## 📋 Project Overview

HealthKart is a static healthcare website that offers a one stop solution for all health-related products and services. I have kept the design minimalist and clean, helping users easily find what they need using universal search feature. 

Users can quickly explore various products by selecting their symptoms or by browsing categories. The website is fully responsive, ensuring a seamless experience across devices. It also features a contact form for inquiries and support.

It also includes a Responsive Navigation Bar that automatically hides on mobile devices and instead shows a hamburger menu.
